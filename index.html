车型管理（T = 车型 SOP 量产日）

每个车型有自己的 T（SOP），显示在泳道第一列并对应一条 T 线。点行尾 × 即时删除车型，并一并删除其名下所有滑块（不可撤销）；改名 / 改 SOP / 新增 需点右下角「保存」才生效。改动 SOP 后滑块真实日期不变，仅相对刻度重新解读。

品牌管理（新增 / 删除车企）

新增后会出现在左侧目录、统计卡、泳道第一列，与各下拉框中。可删除自定义品牌（默认四品牌不可删）；删除会一并移除其车型与滑块，不可撤销。

① 按车型 SOP 自动生成培训滑块

填入车型名称与SOP 量产日（T），系统按标准培训节奏模板（认知 → 技能 → 实战 → 工具）围绕该车型的 T 自动生成一组滑块；日期按相对刻度换算为真实日期。可勾选需要的项、修改标题。

导入 Excel / CSV 表格

可识别列名（顺序不限）：
车企 / 品牌、车型、车型SOP、工作事项 / 培训名称 / 事项、开始日期、结束日期、阶段、类别、地点 / 形式、状态、对象 / 人数、备注。
有「车型 + 车型SOP」时会自动建立车型并关联 T；也可用相对刻度列 起始刻度/结束刻度（T-6M … T+6M）。点「模板」下载标准 CSV。
